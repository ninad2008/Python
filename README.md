📘 Student Report Generator (Python)
-

This Python program collects a student's basic details and marks, then calculates the total, average, and determines whether the student has passed or failed.

✔️ Features
-

Takes student name and roll number as input

Accepts marks for Maths, Science, and English

Calculates:

Total Marks

Average Marks

Automatically determines Pass/Fail

Displays a clean student report


📝 How It Works
-

1️⃣ Input Section
-

The program begins by asking the user for:

Student name

Roll number

Marks in Maths, Science, and English

It stores each value inside a variable.

2️⃣ Processing Section
-

The program performs two main calculations:

Total Marks = maths + science + english

Average = Total / 3

3️⃣ Decision Making
-

A simple condition determines the result:

If the total marks are 60 or more, the student passes

If the total marks are less than 60, the student fails

4️⃣ Output Section
-

Finally, a neat report is printed showing:

Student name

Roll number

Total marks

Average marks

Pass/Fail status
